# RX980 键盘设置

[![RX980 checks](https://github.com/whyIMBA/rx980/actions/workflows/ci.yml/badge.svg)](https://github.com/whyIMBA/rx980/actions/workflows/ci.yml)

RXSTORM RX980 的本地键盘设置工具。开源仓库：[whyIMBA/rx980](https://github.com/whyIMBA/rx980)。

此版本基于 [sharkfin 0.10.0](https://github.com/dniminenn/sharkfin/tree/v0.10.0)，补充 RXSTORM RX980 的识别、98 键布局和通信等待处理。运行时不依赖原厂程序或其服务器。保留 GPL-3.0-or-later 许可及第三方声明。

## 启动

源码克隆后需先按[开发说明](docs/DEVELOPMENT.md)构建，生成 `outputs/rx980-local/`。本地分发包已包含构建产物。需要 Node.js 22 或以上版本，以及 Edge 或 Chrome。

1. 关闭原厂 RXSTORM 软件，用数据线连接键盘并切换到有线模式。
2. 双击本目录的 `启动RX980.cmd`。
3. 在打开的窗口中点击“连接键盘”，选择 `RX980 Gaiming Keyboard`。不要选 `2.4G Wireless Keyboard`。
4. 在“设备”页面先导出一份备份，再进行个人设置。

程序通过本机 Edge 或 Chrome 的键盘接口工作，网址为 `http://127.0.0.1:19806`，资源全部保存在本地。地址只监听本机。首次选择键盘后，浏览器会保存此地址的设备访问许可。

已通过本机 Edge 的实际 WebHID 连接与配置导出验证。设备没有序列号，浏览器或设备重启后可能需要重新选择键盘。

关闭窗口会结束键盘操作。本地文件服务仍可保留，或双击 `停止RX980.cmd` 结束服务。启动入口使用普通 Node.js 本地文件服务，不使用被火绒拦截的 PowerShell 后台启动脚本，不修改安全软件设置。

应用运行临时文件和专用浏览器配置均保存在项目目录。系统自身管理的浏览器和安全软件日志不由本应用指定。

## 当前功能与验收范围

| 项目 | 状态 |
| --- | --- |
| RX980 编号 671、固件 5.05、有线连接 | 已识别 |
| 98 键布局与出厂槽位 | 已对照固件和实机配置 |
| 灯光亮度、配置切换、普通层和 Fn 层改键 | 写入、读回、恢复通过 |
| 消抖、休眠、Windows 键锁定 | 写入、读回、恢复通过 |
| 宏存储 | 空槽位写入、256 字节读回、恢复通过；未播放 |
| 自动识别电脑系统 | 此固件不回答对应读取指令，已隐藏 |
| 无线设置、全灯效、逐键配色、实际改键输出及宏播放 | 尚未验收 |
| 固件更新、云端账号与同步 | 不包含 |

写入一项设置可能等待约两秒。请等待操作完成后再切换功能页。

## 文件位置

| 路径 | 用途 |
| --- | --- |
| `outputs/rx980-local/` | 可运行的本地应用 |
| `sharkfin/` | 开源基线和本次修改的完整源码，由本仓库直接跟踪 |
| `sharkfin/docs/RX980.md` | 适配证据、实现位置和未验收项目 |
| `backups/` | 修改前的配置和宏原始备份，以及应用导出备份 |
| `reports/` | HID 读写及恢复记录、界面验证结果和截图 |
| `scripts/` | 构建、启动服务和硬件验证脚本 |
| `docs/UPSTREAM.md` | 上游基线、来源和许可 |
| `docs/DEVELOPMENT.md` | 构建、检查和打包 |
| `docs/ROADMAP.md` | 待验收项目和后续迭代 |
| `.venv/` | 本地的硬件诊断依赖 |
| `.toolchain/`、`.build/` | 本地的编译工具和缓存 |

`rx980-日期.json` 是带原始数据和全部 50 个宏槽位的诊断备份，不能直接从应用“导入”。`rx980-sharkfin-backup.json` 是应用自身导出的格式，可在应用中使用。上游应用的配置导出不包含宏内容，完整宏数据另保存在原始备份里。

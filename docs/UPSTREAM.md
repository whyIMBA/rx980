# 上游与许可

本项目导入 [dniminenn/sharkfin](https://github.com/dniminenn/sharkfin) 的 v0.10.0 源码快照，基线提交为 `b36c790`。完整上游版权、GPL 许可和第三方声明保留在 `sharkfin/`，仓库根目录同时提供许可副本。

`sharkfin/` 是本仓库直接跟踪的源码目录，不是嵌套 Git 仓库或子模块。本仓库从独立的 `main` 分支继续迭代，上游历史可在原仓库查询。

RX980 的设备识别、98 键布局、通信等待、能力判断和简体中文适配见 [适配记录](../sharkfin/docs/RX980.md)。本项目增加了本地启动、诊断、构建和打包脚本。

上游软件及本项目适配采用 GPL-3.0-or-later。原作者及各依赖的署名按原文件保留。项目与 RXSTORM 厂商无隶属关系，未包含原厂程序或其界面资源。
